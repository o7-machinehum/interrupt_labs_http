# Rookit Labs Blog
Static site generated by Hugo.

Install Hugo 0.167.0 to match the version used by GitHub Actions. Node.js and npm
dependencies are not required to build the site.

## Getting Started
``` bash
hugo server --buildFuture --disableFastRender
```

## Generating Page
``` bash
hugo --cleanDestinationDir --minify
```

The generated site is written to `docs/`, which is ignored by Git. Commit changes
to `content/`, `layouts/`, `static/`, and the site configuration instead.

## Deployment

[GitHub Actions](.github/workflows/pages.yml) builds and deploys the site to GitHub
Pages whenever changes are pushed to `master`. It uploads `docs/` as a Pages
artifact, so generated files do not need to be committed. You can also run the
workflow manually from the Actions tab with the `master` branch selected.

In the repository's **Settings > Pages > Build and deployment**, the source must
be **GitHub Actions**. Keep the custom domain set to `rootkitlabs.com`; the source
file `static/CNAME` is also copied into each build.

See the [Hugo GitHub Pages deployment guide](https://gohugo.io/host-and-deploy/deploy-to-github-pages/)
for details on the Pages setup.
